## 계산

- **절기·삭** — VSOP87 로 직접 계산. 한국천문연구원 발표와 분 단위 일치
- **사주** — 년주는 입춘, 월주는 12절기 + 오호둔, 일주는 율리우스일 60갑자, 시주는 오자둔(야자시 적용)
- **음양력** — 삭과 중기로 윤달 직접 판정. 1988 설날의 한국(2/18)·중국(2/17) 차이까지 정확
- **표준시** — 1954~61 UTC+8:30, 1948~88 서머타임 반영
- **대운** — 양남음녀 순행 / 음남양녀 역행, 절입까지의 일수 ÷ 3

계산 규칙은 전통 명리 그대로이고, **풀이 문장은 전부 직접 썼습니다.** 시중 책이나 사이트의
번역문을 옮겨 쓰지 않았습니다.

## 기술

Cloudflare Workers + D1. 프레임워크 없이 단일 `app.html` + 워커 하나.

```
index.js     라우팅 · API · 페이지 렌더
app.html     프런트 전체 (단일 파일)
saju.js      사주 산출 · 십신 · 합충 · 지장간
astro.js     절기 · 삭 · 음양력 · ΔT      vsop.js  VSOP87
deep.js      사주 심화 (격국·용신·신살·대운·일주론)
fortune.js   오늘의 운세 (12시진 · 띠 · 주간)
life.js      분야별 아홉 갈래
compat.js    관계 판정 + 관계 심화        topics.js  분야별 지도 레지스트리
wealth.js love.js work.js   분야별 점수 엔진
tojeong.js   토정비결 144괘
legal.js     이용약관 · 개인정보처리방침   auth.js  소셜 로그인
tools/mkog.py  페이지별 OG 썸네일 생성
```

배포는 GitHub 푸시 → Workers Builds 자동 배포.
